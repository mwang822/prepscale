# PrepScale — Free Hosted Version

This is a static PWA. It needs no server, database, API, or paid hosting.

## Publish free with GitHub Pages

1. Create a new GitHub repository, e.g. `prepscale`.
2. Upload **all files in this folder** to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public `github.io` URL.
7. Open that URL on your phone/iPad and use **Add to Home Screen**.

The app is static and caches itself for offline use after the first successful load.

## Notes

- Recipe formulas are included only where established in the supplied project recipe information.
- The uploaded drinks menu was used to confirm the cocktail names/descriptions; missing production quantities were not invented.
- Compatible unit conversion is limited to volume-to-volume (oz/ml) and exact-unit scaling. Mass is never silently converted to volume.
- Standard bitters conversion: 70 dashes = 0.25 oz.
